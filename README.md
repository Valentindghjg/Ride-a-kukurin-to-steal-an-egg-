# Ride a Kukurin to Steal an Egg

Roblox-Spielprojekt von Valentin. Dieses Repository ist ab sofort der zentrale Speicherort für Spielkonzept, Planung, Skripte und versionierbare Projektdateien.

## Spielidee

Das Spiel orientiert sich an **Steal an Egg**. Spieler fahren einen E-Scooter, stehlen Eier und investieren verdientes Geld in ihren Scooter. Die persönliche Laufgeschwindigkeit wird als Fortschrittssystem durch Scooter-Upgrades und den Kauf besserer Modelle ersetzt.

Die Modelle werden zunehmend teurer. Dadurch bleiben spätere Scooter langfristige Ziele.

Valentins gewünschte Richtung: Map und Eier sollen sich sehr eng an Steal an Egg orientieren. Die konkrete Referenz und ihre Details müssen vor der Umsetzung noch gemeinsam geprüft werden.
