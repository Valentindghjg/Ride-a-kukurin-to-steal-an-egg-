# Ride a Kukurin to Steal an Egg

Ein Roblox-Spiel von Valentin. Auf dem Kukurin trainierst du beim Fahren Speed, holst Eier aus einer langen Zonenstrecke und bringst sie in dein Gehege. Dort verdienen die Tiere Geld pro Sekunde. Zum freien Fahren und für Wheelies gibt es eine zweite Welt.

Öffne [Ride a Kukurin to Steal an Egg.rbxlx](Ride%20a%20Kukurin%20to%20Steal%20an%20Egg.rbxlx) in Roblox Studio. Der lokale Startplatz enthält eine Grundplatte und einen Spawnpunkt. Die Spielmechaniken sind im Konzept beschrieben.

Die neun freigegebenen Bilder zeigen Wege, Blickwinkel und Bedienung. Die Stadt im Spiel soll einfacher, blockiger und weniger realistisch wirken als die Illustrationen.
